Adaptive Precision Dynamics in Deep Active Inference:
Emerging Driving Behaviors from a Single World Model

Lane keeping, obstacle avoidance, and post-evasion centering emerge from a single EFE objective via adaptive precision-weighting.

Jaerock Kwon1 · Elahe Delavari1 · Donghyun Kim2 · Haewoon Nam2
1 University of Michigan – Dearborn · 2 Hanyang University, South Korea
Code & Docs Paper (coming soon) Citation

Research Overview

Problem. Active inference promises unified perception, learning, and action through free energy minimization. But can a single EFE objective produce multiple distinct driving behaviors? And can safety-critical obstacle detection emerge from the learned latent space?

Contributions.

  • A multi-component EFE formulation combining latent-space instrumental value (GMM), ensemble-based epistemic value, decoded state-space preferences, and obstacle penalties.
  • An adaptive precision-weighting mechanism where sensory prediction errors dynamically modulate EFE component weights, enabling lane keeping, obstacle avoidance, and post-evasion centering from a shared world model.
  • A posterior-prior epistemic gap discovery: the RSSM posterior perfectly encodes obstacles (276 nats via auxiliary head), but the transition model cannot propagate this through imagination — isolated via controlled ablation.

Method: Adaptive Precision Dynamics

The agent loop: Observe → Encode → RSSM Posterior → iCEM Plan (EFE Scoring) → Act. A single world model (RSSM, deter=256, stoch=64) is shared across all tasks. Behavioral differences emerge entirely from runtime modulation of EFE precision weights βi, βs, βo.

STATE ERROR MODULATION
High error → βs↑, βi↓
OBSTACLE PROXIMITY
Near obstacle → βi↓ (suppress preference)
POST-EVASION
After clearance → βs=0.5 (centering)

Posterior-Prior Epistemic Gap

We investigate whether obstacle detection can emerge from the latent space alone, removing all privileged obstacle coordinates. The result: a fundamental gap between what the model knows (posterior) and what it can imagine (prior).

Method Posterior Gap (nats) Driving (MLD) Avoidance
Single GMM (64×64)−24.60.31m0%
Single GMM (128×128)−2.30.17m0%
Contrastive preference+37.00.17m0%
Auxiliary head+2760.30m0%

The auxiliary head achieves perfect posterior separation (0.000 vs 1.000) and 276 nats contrastive gap — yet avoidance remains at 0%. This isolates the blind spot to the RSSM transition model: the representation is adequate, but the dynamics model f(ht, zt, at) → ht+1 cannot learn obstacle-conditioned dynamics.
